Workshop in Class for Application Rubrics

A structured rubric framework for evaluating five core English language skills: Speaking, Listening, Reading, Writing, and Vocabulary — each paired with a dedicated digital application.

✦ ICT in Class Dr. Gusti Nur Hafifah, S.Pd., M.Pd. h
What is an Application Workshop Rubric?
An Application Rubric is a scoring tool used in language education to evaluate learner performance across specific skill areas. Each rubric defines clear criteria and descriptors for multiple score levels, enabling consistent and transparent assessment for description class strategy. This workshop applies rubric-based evaluation to five macro skills of English Language Teaching (ELT): Speaking, Listening, Reading, Writing, and Vocabulary — each integrated with a specific digital application and tailored to a target grade level.
