Application Rubrics

A structured rubric framework for evaluating five core English language skills: Speaking, Listening, Reading, Writing, and Vocabulary — each paired with a dedicated digital application.

✦ Overview
What is an Application Rubric?
An Application Rubric is a scoring tool used in language education to evaluate learner performance across specific skill areas. Each rubric defines clear criteria and descriptors for multiple score levels, enabling consistent and transparent assessment. This workshop applies rubric-based evaluation to five macro skills of English Language Teaching (ELT): Speaking, Listening, Reading, Writing, and Vocabulary — each integrated with a specific digital application and tailored to a target grade level. Click any skill card below to read the full article, including criteria, scoring descriptors, and classroom reflection.
