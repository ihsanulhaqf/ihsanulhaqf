Application Rubrics

A structured rubric framework for evaluating the four core English language skills: Speaking, Listening, Reading, and Writing.

✦ Overview
What is an Application Rubric?
An Application Rubric is a scoring tool used in language education to evaluate learner performance across specific skill areas. Each rubric defines clear criteria and descriptors for multiple score levels, enabling consistent and transparent assessment. This workshop applies rubric-based evaluation to the four macro skills of English Language Teaching (ELT): Speaking, Listening, Reading, and Writing.
